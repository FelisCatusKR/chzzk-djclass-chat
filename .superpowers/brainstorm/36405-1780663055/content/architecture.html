Key Design Decisions

  • Next.js App Router — handles SSR pages + API routes in one process
  • SQLite — file-based, perfect for single-node Dokku deploy (volume mount for persistence)
  • Separate Worker — cron jobs isolated from web traffic, won't slow down chat widget
  • OBS Browser Source — widget is just a transparent web page with WebSocket/SSE for live chat
